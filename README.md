# KILLER Telegram Manager · ALLPLUS

مدیر شخصی تلگرام با رابطِ بات و Mini App فارسی/انگلیسی. هر دو رابط از یک نشست MTProto، سرویس مشترک و پایگاه SQLite استفاده می‌کنند. برنامه را روی رایانه یا سرور خودتان اجرا کنید.

| قابلیت | امکانات |
| --- | --- |
| گفت‌وگوها | کانال، گروه، بات، خصوصی، بایگانی، پوشه، جست‌وجو، صفحه‌بندی، خروج، بایگانی و سنجاق تکی |
| پیام و رسانه | تاریخچه، جست‌وجو، ذخیره‌شده‌ها، پیش‌نویس، سنجاق‌شده و زمان‌بندی‌شده، فیلترهای رسانه، دانلود انتخابی |
| مخاطب و پروفایل | همگام‌سازی، مخاطب با نام کاربری، ویرایش، حذف با تأیید، حساب و عکس‌های پروفایل |
| امنیت و فعالیت | دستگاه‌ها، وضعیت دومرحله‌ای، حریم خصوصی قابل‌خواندن، پایان نشست دیگر با تأیید، تاریخچهٔ عملیات |
| دادهٔ محلی | آمار همگام‌سازی و نمودار روند، علاقه‌مندی، برچسب، بازدید اخیر، تاریخچهٔ رمزگذاری‌شدهٔ جست‌وجو |
| پشتیبان و کارهای دوره‌ای | پشتیبان رمزگذاری‌شده، بررسی و بازیابی در فایل تازه، خروجی آمار، خلاصهٔ روزانه، هشدار نشست تازه |

The bot and Mini App manage one owner’s Telegram account. Install Python 3.11+, copy `.env.example` to `.env`, provide your own Telegram API credentials and bot token, then run `python -m app.main`. Choose **English** in bot settings or the Mini App toolbar.

## راه‌اندازی روی ویندوز

۱. در PowerShell با Python 3.11 یا جدیدتر محیط مجازی بسازید و وابستگی‌ها را نصب کنید.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

۲. فایل `.env` را محلی ویرایش کنید.

- `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` را از [درگاه توسعه‌دهندگان تلگرام](https://my.telegram.org) بگیرید.
- با [BotFather](https://t.me/BotFather) یک بات اختصاصی بسازید و توکن را در `TELEGRAM_BOT_TOKEN` بگذارید.
- شناسهٔ عددی همان حسابی را که با MTProto وارد می‌کنید در `TELEGRAM_OWNER_ID` بگذارید. برنامه همین شناسه را برای حساب شخصی و پیام‌های بات بررسی می‌کند.
- خروجی فرمان تولید کلید را در `KILLER_SESSION_KEY` بگذارید. برای بازکردن نشست ذخیره‌شده به همان کلید نیاز دارید.

اگر شناسهٔ خودتان را نمی‌دانید، پیش از اجرای برنامه به **بات خودتان** در گفت‌وگوی خصوصی `/start` بفرستید. سپس از ترمینال محلی فرمان زیر را اجرا کنید و شناسهٔ پیام ارسالی خودتان را بردارید. فرمان فقط از Bot API تلگرام استفاده می‌کند.

```powershell
@'
from dotenv import dotenv_values
import httpx

token = dotenv_values(".env", interpolate=False)["TELEGRAM_BOT_TOKEN"]
try:
    result = httpx.post(
        f"https://api.telegram.org/bot{token}/getUpdates",
        json={"allowed_updates": ["message"]},
        trust_env=False,
        timeout=10,
    ).json()
    if result.get("ok"):
        for update in result["result"]:
            message = update.get("message", {})
            if message.get("chat", {}).get("type") == "private":
                print(message["from"]["id"], message["from"].get("username", ""))
    else:
        print("Bot API error:", result.get("error_code"))
except (httpx.RequestError, ValueError):
    print("Bot API connection failed")
'@ | .\.venv\Scripts\python.exe -
```

۳. برنامه را از پنجرهٔ PowerShell اجرا کنید و در بات `/start` بفرستید.

```powershell
.\.venv\Scripts\python.exe -m app.main
```

در اولین اجرا، شماره با پیش‌شمارهٔ کشور، کد ارسال‌شده از طرف تلگرام و در صورت نیاز رمز دومرحله‌ای را در ترمینال وارد کنید. ورود کد و رمز با ورودی پنهان انجام می‌شود. اگر کد منقضی شده یا نشست در حین کار نامعتبر شده است، برنامه را در ترمینال دوباره اجرا کنید. بات به اتصال خروجی به Bot API و سرورهای MTProto نیاز دارد. webhook یا نمونهٔ دیگری از polling نباید هم‌زمان از همین توکن استفاده کند.

برای ورود با QR، فرمان اجرا را با گزینهٔ `--qr` در ترمینال خصوصی اجرا کنید. بعد از زدن Enter، نشانی موقت `tg://login` را با یک ابزار محلی به QR تبدیل کنید و از بخش «دستگاه‌ها» در تلگرام اسکن کنید. برای هر تلاش، QR معتبر همان تلاش را اسکن کنید. اگر تلگرام رمز دومرحله‌ای خواست، آن را در ترمینال وارد کنید.

## اجرای Mini App

در «ابزارها ← مدیریت چت‌ها» کانال‌ها، گروه‌ها و بات‌های دلخواه را انتخاب کنید. از «صف عملیات» انتخاب‌ها را مرور و اجرا را تأیید کنید. پیوندهای در دسترس، نام، شناسه و جزئیات قابل‌دریافت پیش از عملیات به‌صورت رمزگذاری‌شده ذخیره می‌شوند. نتیجه از «گزارش عملیات» در دسترس است. پیوند دعوت خصوصی ممکن است در دسترس نباشد یا بعداً منقضی شود.

```powershell
.\.venv\Scripts\python.exe -m app.main --web-port 8765
```

صفحهٔ محلی برای بررسی رابط در `http://127.0.0.1:8765/` است. API فقط دادهٔ ورود امضاشدهٔ تلگرام برای شناسهٔ مالک را می‌پذیرد. برای استفادهٔ واقعی، نشانی HTTPS عمومیِ معتبر را در `KILLER_MINIAPP_URL` بگذارید و پراکسی را به همین پورت محلی یا سوکت `--web-socket` وصل کنید. راهنمای cPanel و معماری در [docs/architecture.md](docs/architecture.md) است.

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
.venv/bin/python -m app.main --qr --web-socket
```

برای اجرای غیرتعاملی بعد از ذخیرهٔ نشست، `--qr` را بردارید. کلید رمزگذاری و توکن را در محیط محافظت‌شده نگه دارید.

## پشتیبان و بازیابی

بات یا Mini App می‌تواند از دادهٔ برنامه نسخهٔ پشتیبان بسازد. پشتیبان تاریخچهٔ پیام‌های تلگرام یا نشست MTProto را شامل نمی‌شود. برای کار آفلاین، ابتدا نمونهٔ فعال را متوقف کنید.

```text
python -m app.main --backup
python -m app.main --preview-backup NAME.fernet
python -m app.main --restore-backup NAME.fernet restored.sqlite3
python -m app.main --export-organizer organizer.json
python -m app.main --preview-organizer organizer.json
python -m app.main --import-organizer organizer.json --confirm-import
```

بازیابی فقط در مسیر تازه انجام می‌شود. واردکردن Organizer برچسب و علاقه‌مندی را فقط برای شناسه‌های موجود در پایگاه همین حساب به‌روز می‌کند. تنظیم نگهداری پشتیبان در Mini App قابل تغییر است. زمان اجرای کار روزانه بر اساس UTC و فاصلهٔ زمانی `KILLER_SYNC_INTERVAL` است.

## رفتار برنامه

- داشبورد شمار کل گفت‌وگوهای MTProto، از جمله گفت‌وگوهای بایگانی‌شده، و شمار کانال‌ها و گروه‌های فعلی را نشان می‌دهد. گروه‌های مهاجرت‌کرده در فهرست گروه‌ها به صورت سوپرگروه مقصد نمایش داده می‌شوند.
- فهرست‌ها فیلتر عمومی و خصوصی دارند. برای رفتن مستقیم به یک صفحه، روی شمارهٔ صفحه بزنید و با رقم فارسی یا انگلیسی پاسخ دهید. جست‌وجوی عنوان تفاوت «ی/ي»، «ک/ك» و فاصله‌ها را در نظر می‌گیرد. تازه‌سازی، صفحه و فیلتر جاری را حفظ می‌کند.
- اطلاعات تکمیلی و عکس هنگام انتخاب مورد گرفته می‌شوند. جزئیات، دکمهٔ کپی شناسه و برای موارد عمومی دکمهٔ بازکردن در تلگرام دارد. پیوند دعوت موجود و مجاز نمایش داده می‌شود. ظاهر بات از دکمه‌ها و قالب‌بندی بومی تلگرام استفاده می‌کند و به Premium نیاز ندارد.
- هر خروج تأیید انفرادی و یک‌بارمصرف دارد. اگر تلگرام عضویت یا نتیجهٔ خروج را به‌روشنی گزارش ندهد، برنامه وضعیت را نامشخص اعلام می‌کند. خروج از بعضی چت‌ها، مانند کانال تحت مالکیت حساب، ممکن است از سمت تلگرام رد شود.
- همگام‌سازی در پس‌زمینه انجام می‌شود. در محدودیت موقت MTProto، مدت انتظار اعلام می‌شود و امکان تازه‌سازی بعد از پایان آن وجود دارد.
- تفکیک سرویس حساب، پایگاه داده و رابط بات اجازه می‌دهد در آینده رابط دیگری بر همان سرویس‌ها ساخته شود.

## نگهداری داده

نشست MTProto به‌صورت رمزگذاری‌شده در `data/account.fernet` ذخیره می‌شود. کلید و فایل نشست را جداگانه محافظت کنید. SQLite شامل عنوان‌ها، نام‌های کاربری، شناسه‌ها و شمار گفت‌وگوهاست. عکس‌ها، درباره و پیوندهای دعوت برای مدت محدود در حافظه نگه داشته می‌شوند. اطلاعاتی که در بات باز می‌کنید از مسیر تلگرام به گفت‌وگوی خصوصی بات ارسال می‌شود. از یک حساب سیستم‌عامل اختصاصی یا دسترسی محدود به پوشهٔ پروژه استفاده کنید.

## آزمون‌ها

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

آزمون‌های خودکار بدون حساب واقعی و با جایگزین‌های محلی اجرا می‌شوند. برای آزمون سرتاسری، ابتدا ورود و شمارها را با حساب خودتان مقایسه کنید. فهرست گروه و کانال، صفحه‌ها، جست‌وجو و صفحهٔ اطلاعات را باز کنید. برای آزمودن خروج، یک چت آزمایشی را که مالک آن نیستید انتخاب کنید. یک‌بار لغو کنید، سپس در درخواست تازه خروج همان چت را تأیید کنید و نتیجه را در تلگرام و فهرست بات بررسی کنید.

## محدوده و انتشار

- حذف پیام عادی به پیام‌های ارسالیِ حساب محدود است. حذف پیام کانال تابع رفتار تلگرام است. در گفت‌وگوهای غیرکانال درخواست حذف برای خود حساب ثبت می‌شود. حذف زمان‌بندی‌شده و ذخیره‌شده نیز تأیید جداگانه دارد.
- تنظیمات حریم خصوصی و 2FA برای مشاهده‌اند. در حالت خصوصی، ورود حساب از ترمینال انجام می‌شود. دانلود رسانهٔ محافظت‌شده یا بزرگ‌تر از ۲۰ مگابایت غیرفعال است.
- پوشه‌ها، شمار اعضا و رسانه به اطلاعات و مجوزهای تلگرام وابسته‌اند. نمودارها از داده‌های محلی ساخته می‌شوند. ساختار پروفایل‌های جدا پشتیبانی می‌شود، ولی جابه‌جایی حساب از رابط و پلاگین کدِ شخص ثالث در این نسخه فعال نیستند.
- گزارش امنیتی در [SECURITY.md](SECURITY.md) و مجوز در [LICENSE](LICENSE) قرار دارد. فرمان `python scripts/release.py` بستهٔ عمومی تک‌مالک را از فهرست مجاز فایل‌های منبع می‌سازد و کنترل اولیهٔ داده‌های شبیه اعتبارنامه را اجرا می‌کند.
